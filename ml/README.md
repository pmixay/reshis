# Искусственный интеллект: прогноз спроса на авиабилеты

Ноутбук [`notebook/ml_demand_forecast.ipynb`](notebook/ml_demand_forecast.ipynb) — исходный ноутбук кейса, в котором
заполнены все ячейки-решения (`# Ваш код здесь` и `**Ваш ответ:**`) и сохранён вывод каждой ячейки.
Готовые ячейки кейса не изменялись. Результат задания 7 — [`notebook/my_forecast.csv`](notebook/my_forecast.csv)
(прогноз спроса в 9 сценариях и лучшие цены на 1 июня – 1 июля 2026); этот же файл использует сервис из части «Разработка».

## Что сделано

| Задание | Решение |
|---|---|
| 1. Исследование данных | графики по маршрутам, разбор праздников, недельной сезонности, разового провала MOW-AER в июле 2023 и нового маршрута MOW-MRV |
| 2. Модели AutoGluon | 3 конфигурации (`medium_quality`, `high_quality`, свой набор с Chronos-2 small/base и табличными моделями), метрика MAE, 9 квантилей, 3 окна валидации |
| 3. Признаки | `add_features(df)`: дни перед длинными выходными, нерабочие праздники, 1–2 января + статический признак «деловой маршрут» |
| 4. Модель для бизнеса | правило «самая быстрая модель в пределах 5% от лучшей по MAE» → `final_model` |
| 5. Тест | MAE на мае 2026 (один раз, только для выбранной модели), разбор по маршрутам и дням, покрытие интервала |
| 6. Финальный прогноз | переобучение на train + test, признаки на 31 будущий день, график прогноза и ширины интервала |
| 7. Цены | готовые ячейки кейса, файл `my_forecast.csv` |

## Запуск

В Google Colab: открыть ноутбук и выполнить все ячейки (первая ячейка установит AutoGluon и скачает данные).

Локально (Python 3.12):

```bash
pip install -r ml/requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
cd ml/notebook && jupyter nbconvert --to notebook --execute --inplace ml_demand_forecast.ipynb
```

Данные берутся из `data/ml_case/public/` (путь `../../data/ml_case/public/` из ячейки подготовки), обученные модели
сохраняются в `ml/notebook/autogluon-models/` (в git не попадают). Полный прогон на 4 CPU — около часа, почти всё
время уходит на пресет `high_quality` (нейросети TFT и DeepAR, дообучение Chronos-2).

Нейросетевые модели (TFT, DeepAR) обучаются с ограничением по времени, поэтому при повторном запуске их ошибка может
немного отличаться; выводы в ответах относятся к сохранённому в ноутбуке запуску.
